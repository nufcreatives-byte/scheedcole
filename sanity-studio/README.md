# Scheed Cole Studio — preparation

This is a draft Sanity Studio for Home, Work and Press. It is not connected to the public website and does not publish changes to it.

Create a Sanity project and dataset under the intended owner's account, copy .env.example to .env.local, and fill in the project ID. Install dependencies and run npm run dev. Do not put credentials or tokens in this repository.

Before launching: import and reconcile existing page content and images, connect and test the website's rendering (including individual project pages), choose a Studio hosting URL, configure CORS and editor access, test publishing and removals end to end, and decide ownership. Product and checkout features are deliberately deferred.
