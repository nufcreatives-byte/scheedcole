# Editing Scheed Cole’s website

This editor is prepared on the `cms-content-preparation` branch. Open https://app.pagescms.org/, sign in with an authorized GitHub account, choose the Scheed Cole repository, and select the correct branch before editing. Saving commits changes to that branch. The public website updates only when changes reach the GitHub Pages publishing branch.

## Home
Open Home, edit the fields and save. Editing the practice statement may remove its original italic emphasis.

## Work
Open Work listings and expand a project. Edit its listing text, cover, page heading, introduction, main photo, individual existing text blocks and additional photographs. Original position and photo count fields are technical identifiers: do not change them. Existing project pages have individually designed layouts; extra photos appear in a new gallery near the bottom. To add a project, add an item, fill in its title, location, type, description and cover, and leave the existing page field blank. A page and stable project ID are generated automatically. The additional story and gallery fields can be used for new projects.

## Press
Press listings controls the main Press page. Project press pages controls the articles on each separate project press page; the two lists are independent. Enter complete https:// links. Use YYYY-MM-DD for the optional main-list sorting date.

## Access and publishing
Give each editor their own GitHub account and repository access. Do not share credentials. After saving, check the public website once the GitHub Pages deployment completes. The updated content requires JavaScript; original static markup remains a fallback. Shop and payment functions are not included and will be planned separately.
