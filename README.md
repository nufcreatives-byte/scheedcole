# Scheed Cole — Portfolio Website

Portfolio website for **Scheed Cole**, Jamaican sculptor, designer, fabricator and visual artist.

## Positioning

Scheed creates bespoke sculpture, public art, attractions, themed environments and custom fabricated works for public, cultural and commercial spaces.

## Visual direction

**Editorial · Architectural · Tactile · Monumental**

The website uses warm off-white, charcoal and earthy bronze tones, oversized typography and generous negative space. The interface stays deliberately restrained so Scheed's sculpture and project photography become the dominant visual language.

The goal is to position the practice beyond a conventional artist portfolio: a studio capable of taking ambitious ideas from concept through design, fabrication and installation.

## Homepage structure

1. Hero — Scheed Cole / Sculptor · Designer · Fabricator
2. Positioning statement
3. Selected work
4. Practice / About Scheed
5. Capabilities
6. Process — Concept → Design → Fabrication → Installation
7. Commission call-to-action
8. Contact

## Project categories

- Monumental & Public Sculpture
- Attractions & Themed Environments
- Culture & Heritage
- Custom Fabrication
- Sustainable / Recycled Art

## Development

Initial version is intentionally dependency-free HTML/CSS/JS so it can be hosted easily with GitHub Pages or migrated into a framework later.
